   248→   647→   647→   647→### ⚠️ Cover Content Overflow Prevention (Mandatory)
   249→   648→   648→   648→
   250→   649→   649→   649→1. Cover section page margin is 0; total content height ≤ 15638 twips (1200 twips safety margin for cross-engine compatibility — MS Office renders large fonts taller than calculated).
   251→   650→   650→   650→2. Color block Table `height` must use `rule: "exact"` (never `"atLeast"`).
   252→   651→   651→   651→3. Each recipe code includes height budget annotations — verify during generation.
   253→   652→   652→   652→4. **`verticalAlign` must always be `"top"`**. Never use `"center"` or `"bottom"` in exact-height rows — content will be clipped or overflow. Use `spacing.before` on the first paragraph for vertical positioning.
   254→   653→   653→   653→5. **Title font size MUST be dynamically calculated via `calcTitleLayout()`** (see below). Never hardcode font sizes above 40pt for cover titles. Every recipe MUST call `calcTitleLayout()` before building title paragraphs.
   255→   654→   654→   654→6. **Never use `margins.top`/`margins.bottom` for vertical positioning inside exact-height cells**: Cell margins reduce available height unpredictably across MS Office and WPS. Use `spacing.before` on the first paragraph instead. Only `margins.left`/`margins.right` are safe.
   256→   655→   655→   655→7. **Dynamic spacing is mandatory**: Use `calcCoverSpacing()` to compute `spacing.before` values dynamically based on content element count and title line count. Never use fixed large spacing values (e.g., `before: 4500`) that assume a specific title length.
   257→   656→   656→   656→8. **Cover must be a single-page section**: The cover section must produce exactly ONE page. If content overflows to a second page, it means the height budget is violated. Common overflow causes and fixes:
   258→   657→   657→   657→   - Title font too large → use `calcTitleLayout()` to auto-reduce
   259→   658→   658→   658→   - Too many meta lines → reduce font size or remove less important lines
   260→   659→   659→   659→   - Fixed `spacing.before` values too large → use `calcCoverSpacing()` for dynamic values
   261→   660→   660→   660→   - Subtitle + English label + meta lines combined exceed budget → calculate total and reduce spacing
   262→   661→   661→   661→9. **Cover wrapper table MUST use explicit `allNoBorders`**: The outer 16838 wrapper table and ALL nested tables inside the cover MUST set borders to NONE explicitly. Never rely on docx-js default borders (`single/auto/sz=4`). Default borders add ~8 twips per edge, which causes MS Office to calculate a total height slightly exceeding 16838 → content overflows to a blank page 2. WPS is more lenient but MS Office is strict. **This is the #1 cause of "blank page 2 in MS Office but not in WPS".**

   265→   664→   664→   664→// ✅ MANDATORY: Define and use allNoBorders for every cover table

   273→   672→   672→   672→  // ...
   274→   673→   673→   673→});
   275→   674→   674→   674→```
   276→   675→   675→   675→

   319→   718→   718→   718→### ⚠️ Cover Title Layout — calcTitleLayout() (Mandatory for ALL Recipes)
   320→   719→   719→   719→
   321→   720→   720→   720→**Every cover recipe MUST use `calcTitleLayout()` to determine title font size and line breaks.** Hardcoding font sizes or passing the full title as a single TextRun is FORBIDDEN.
   322→   721→   721→   721→
   323→   722→   722→   722→**Every paragraph with font size > body text MUST set explicit line spacing** to prevent top clipping:
   324→   723→   723→   723→```js
   325→   724→   724→   724→// ★ MANDATORY: prevent inherited small line spacing from clipping large fonts
   326→   725→   725→   725→spacing: { line: Math.ceil(titlePt * 23), lineRule: "atLeast", after: 100 }
   327→   726→   726→   726→// Example: 36pt → line: 828; 44pt → line: 1012
   328→   727→   727→   727→```
   329→   728→   728→   728→Without this, the paragraph inherits body text line spacing (e.g., 560tw), which is shorter than the font height → top of characters gets clipped.
   330→   729→   729→   729→
   331→   730→   730→   730→```js
   332→   731→   731→   731→/**
   333→   732→   732→   732→ * Calculate safe font size and smart line breaks for cover titles.
   334→   733→   733→   733→ * MUST be called by every recipe before building title paragraphs.
   335→   734→   734→   734→ *
   336→   735→   735→   735→ * @param {string}  title          Full title string
   337→   736→   736→   736→ * @param {number}  maxWidthTwips  Available width for title text (twips, after subtracting margins/padding)
   338→   737→   737→   737→ * @param {number}  preferredPt    Desired max font size in pt (default 40)
   339→   738→   738→   738→ * @param {number}  minPt          Minimum allowed font size in pt (default 24)
   340→   739→   739→   739→ * @returns {{ titlePt: number, titleLines: string[] }}
   341→   740→   740→   740→ */
   342→   741→   741→   741→function calcTitleLayout(title, maxWidthTwips, preferredPt = 40, minPt = 24) {
   343→   742→   742→   742→  // Each CJK character width ≈ pt × 20 twips
   344→   743→   743→   743→  const charWidth = (pt) => pt * 20;
   345→   744→   744→   744→  const charsPerLine = (pt) => Math.floor(maxWidthTwips / charWidth(pt));
   346→   745→   745→   745→
   347→   746→   746→   746→  // Try from preferredPt downward until title fits in ≤ 3 lines
   348→   747→   747→   747→  let titlePt = preferredPt;
   349→   748→   748→   748→  let lines;
   350→   749→   749→   749→  while (titlePt >= minPt) {
   351→   750→   750→   750→    const cpl = charsPerLine(titlePt);
   352→   751→   751→   751→    if (cpl < 2) { titlePt -= 2; continue; }
   353→   752→   752→   752→    lines = splitTitleLines(title, cpl);
   354→   753→   753→   753→    if (lines.length <= 3) break;
   355→   754→   754→   754→    titlePt -= 2;
   356→   755→   755→   755→  }
   357→   756→   756→   756→
   358→   757→   757→   757→  // If still > 3 lines at minPt, force 3 lines
   359→   758→   758→   758→  if (!lines || lines.length > 3) {
   360→   759→   759→   759→    const cpl = charsPerLine(minPt);
   361→   760→   760→   760→    lines = splitTitleLines(title, cpl);
   362→   761→   761→   761→    titlePt = minPt;
   363→   762→   762→   762→  }
   364→   763→   763→   763→
   365→   764→   764→   764→  return { titlePt, titleLines: lines };
   366→   765→   765→   765→}
   367→   766→   766→   766→
   368→   767→   767→   767→/**
   369→   768→   768→   768→ * Smart Chinese title line-breaking — breaks at semantic boundaries, never mid-word.
   370→   769→   769→   769→ *
   371→   770→   770→   770→ * Rules:
   372→   771→   771→   771→ * 1. Prefer breaking after particles, punctuation, connectors, underscores, spaces
   373→   772→   772→   772→ * 2. Never split a compound word (e.g., "管理规范" must not become "管理规" + "范")
   374→   773→   773→   773→ * 3. No single-character orphan on the last line — merge into previous line
   375→   774→   774→   774→ * 4. If no good break point found within 60-130% of charsPerLine, break at charsPerLine
   376→   775→   775→   775→ *
   377→   776→   776→   776→ * @param {string} title        Full title string
   378→   777→   777→   777→ * @param {number} charsPerLine Max characters per line at current font size
   379→   778→   778→   778→ * @returns {string[]}          Array of line strings
   380→   779→   779→   779→ */
   381→   780→   780→   780→function splitTitleLines(title, charsPerLine) {
   382→   781→   781→   781→  if (title.length <= charsPerLine) return [title];
   383→   782→   782→   782→
   384→   783→   783→   783→  // Characters that are safe break points (break AFTER these)
   385→   784→   784→   784→  const breakAfter = new Set([
   386→   785→   785→   785→    ...'，。、；：！？',              // CJK punctuation
   387→   786→   786→   786→    ...'的与和及之在于为',            // CJK particles/prepositions
   388→   787→   787→   787→    ...'-_—–·/',                     // connectors
   389→   788→   788→   788→    ...' \t',                         // whitespace
   390→   789→   789→   789→  ]);
   391→   790→   790→   790→
   392→   791→   791→   791→  const lines = [];
   393→   792→   792→   792→  let remaining = title;
   394→   793→   793→   793→
   395→   794→   794→   794→  while (remaining.length > charsPerLine) {
   396→   795→   795→   795→    let breakAt = -1;
   397→   796→   796→   796→
   398→   797→   797→   797→    // Search backward from charsPerLine to 60% for a break point
   399→   798→   798→   798→    for (let i = charsPerLine; i >= Math.floor(charsPerLine * 0.6); i--) {
   400→   799→   799→   799→      if (i < remaining.length && breakAfter.has(remaining[i - 1])) {
   401→   800→   800→   800→        breakAt = i;
   402→   801→   801→   801→        break;
   403→   802→   802→   802→      }
   404→   803→   803→   803→    }
   405→   804→   804→   804→
   406→   805→   805→   805→    // If not found, search forward up to 130%
   407→   806→   806→   806→    if (breakAt === -1) {
   408→   807→   807→   807→      const limit = Math.min(remaining.length, Math.ceil(charsPerLine * 1.3));
   409→   808→   808→   808→      for (let i = charsPerLine + 1; i < limit; i++) {
   410→   809→   809→   809→        if (breakAfter.has(remaining[i - 1])) {
   411→   810→   810→   810→          breakAt = i;
   412→   811→   811→   811→          break;
   413→   812→   812→   812→        }
   414→   813→   813→   813→      }
   415→   814→   814→   814→    }
   416→   815→   815→   815→
   417→   816→   816→   816→    // Last resort: break at charsPerLine, but avoid splitting compound CJK words
   418→   817→   817→   817→    if (breakAt === -1) {
   419→   818→   818→   818→      breakAt = charsPerLine;
   420→   819→   819→   819→      // If both chars at the break boundary are CJK (likely a compound word),
   421→   820→   820→   820→      // step back 1 char to keep the word together
   422→   821→   821→   821→      const prevChar = remaining[breakAt - 1];
   423→   822→   822→   822→      const nextChar = remaining[breakAt];
   424→   823→   823→   823→      if (prevChar && nextChar &&
   425→   824→   824→   824→          !breakAfter.has(prevChar) && !breakAfter.has(nextChar) &&
   426→   825→   825→   825→          /[\u4e00-\u9fff]/.test(prevChar) && /[\u4e00-\u9fff]/.test(nextChar)) {
   427→   826→   826→   826→        breakAt = breakAt - 1;
   428→   827→   827→   827→      }
   429→   828→   828→   828→    }
   430→   829→   829→   829→
   431→   830→   830→   830→    lines.push(remaining.slice(0, breakAt).trim());
   432→   831→   831→   831→    remaining = remaining.slice(breakAt).trim();
   433→   832→   832→   832→  }
   434→   833→   833→   833→  if (remaining) lines.push(remaining);
   435→   834→   834→   834→
   436→   835→   835→   835→  // Prevent single-character orphan on last line — merge into previous
   437→   836→   836→   836→  if (lines.length > 1 && lines[lines.length - 1].length <= 2) {
   438→   837→   837→   837→    const last = lines.pop();
   439→   838→   838→   838→    lines[lines.length - 1] += last;
   440→   839→   839→   839→  }
   441→   840→   840→   840→
   442→   841→   841→   841→  return lines;
   443→   842→   842→   842→}
   444→   843→   843→   843→
   445→   844→   844→   844→/**
   446→   845→   845→   845→ * Calculate dynamic spacing values for cover elements to fit within page height.
   447→   846→   846→   846→ *
   448→   847→   847→   847→ * @param {object} params
   449→   848→   848→   848→ * @param {number} params.titleLineCount   Number of title lines
   450→   849→   849→   849→ * @param {number} params.titlePt          Title font size in pt
   451→   850→   850→   850→ * @param {boolean} params.hasSubtitle     Whether subtitle exists
   452→   851→   851→   851→ * @param {boolean} params.hasEnglishLabel Whether English label exists
   453→   852→   852→   852→ * @param {number} params.metaLineCount    Number of meta info lines
   454→   853→   853→   853→ * @param {number} params.fixedHeight      Sum of fixed-height elements (color strips, accent bars, footer) in twips
   455→   854→   854→   854→ * @param {number} params.pageHeight       Total page height in twips (default 16838)
   456→   855→   855→   855→ * @returns {{ topSpacing, midSpacing, bottomSpacing }}  Spacing values in twips
   457→   856→   856→   856→ */
   458→   857→   857→   857→function calcCoverSpacing(params) {
   459→   858→   858→   858→  const {
   460→   859→   859→   859→    titleLineCount = 1, titlePt = 36, hasSubtitle = false,
   461→   860→   860→   860→    hasEnglishLabel = false, metaLineCount = 0,
   462→   861→   861→   861→    fixedHeight = 800, pageHeight = 16838,
   463→   862→   862→   862→    marginTop = 0, marginBottom = 0,   // ★ NEW: pass actual section margins
   464→   863→   863→   863→  } = params;
   465→   864→   864→   864→
   466→   865→   865→   865→  // ★ Safety margin: 1200 twips (cross-engine: MS Office renders large fonts
   467→   866→   866→   866→  // taller than calculated; extra 400tw buffer prevents footer clipping)
   468→   867→   867→   867→  const SAFETY = 1200;
   469→   868→   868→   868→  // ★ Subtract page margins from available height (cover section may have margins)
   470→   869→   869→   869→  const usableHeight = pageHeight - marginTop - marginBottom - SAFETY;
   471→   870→   870→   870→
   472→   871→   871→   871→  // ★ Accurate height estimation per element:
   473→   872→   872→   872→  const titleHeight = titleLineCount * (titlePt * 23 + 200);
   474→   873→   873→   873→  const subtitleHeight = hasSubtitle ? (12 * 23 + 600) : 0;
   475→   874→   874→   874→  const englishLabelHeight = hasEnglishLabel ? (9 * 23 + 600) : 0;
   476→   875→   875→   875→  const metaHeight = metaLineCount * (10 * 23 + 100);
   477→   876→   876→   876→
   478→   877→   877→   877→  // ★ Account for implicit paragraph heights:
   479→   878→   878→   878→  const implicitParaHeight = 3 * 300;
   480→   879→   879→   879→
   481→   880→   880→   880→  const contentHeight = titleHeight + subtitleHeight + englishLabelHeight +
   482→   881→   881→   881→                        metaHeight + fixedHeight + implicitParaHeight;
   483→   882→   882→   882→
   484→   883→   883→   883→  const remainingSpace = usableHeight - contentHeight;
   485→   884→   884→   884→  const safeRemaining = Math.max(remainingSpace, 400);
   486→   885→   885→   885→
   487→   886→   886→   886→  // ★ Footer protection: bottomSpacing must be ≥ FOOTER_MIN to prevent
   488→   887→   887→   887→  // footer + accent line from being clipped at the cell bottom edge
   489→   888→   888→   888→  const FOOTER_MIN = 800;
   490→   889→   889→   889→  const rawTop = Math.floor(safeRemaining * 0.45);
   491→   890→   890→   890→  const rawBottom = Math.floor(safeRemaining * 0.45);
   492→   891→   891→   891→  const bottomSpacing = Math.max(rawBottom, FOOTER_MIN);
   493→   892→   892→   892→  const topSpacing = Math.max(rawTop - Math.max(0, FOOTER_MIN - rawBottom), 400);
   494→   893→   893→   893→  const midSpacing = Math.max(safeRemaining - topSpacing - bottomSpacing, 0);
   495→   894→   894→   894→
   496→   895→   895→   895→  return { topSpacing, midSpacing, bottomSpacing };
   497→   896→   896→   896→}
   498→   897→   897→   897→```
